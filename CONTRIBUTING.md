# Contributing to Fyrlykta

Thank you for your interest. The full guide lives in the docs site: [docs/docs/contributing.md](docs/docs/contributing.md).

In short:

- Open an issue to discuss a question or propose a change, one topic per issue.
- Work on a branch from `main`, open a draft pull request early, and mark it ready for review when CI passes.
- Write commit messages in English. Pull requests are squash merged.
