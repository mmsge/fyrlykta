# Introduction

Fyrlykta is an open source, public discovery engine for the independent web: Mastodon accounts, blogs and news sites, in any language. It maps how these sites and accounts link to each other, and uses that graph to surface places people would not find inside their own bubble.

The project is at the very start. No stack or implementation has been chosen yet, so this site holds the mission and the shape of the project rather than install or usage instructions.

- Read the [mission brief](./mission-brief.md) for the mission, principles, scope and open questions.
- Read the [contributing guide](./contributing.md) to help shape the project or work on these docs.
